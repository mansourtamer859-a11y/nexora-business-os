# NEXUS SaaS ERP OS NEXUS SaaS ERP OS is an ultra-premium enterprise dashboard and AI operating environment for modern SaaS operations, cross-functional workflows, and executive decision-making. ## Features - Premium cybernetic dark-mode dashboard - Secure multi-stage admin access workflow - Supabase Auth and Google OAuth-ready integration - MFA verification flow for privileged access - AI assistant with persistent message history - Real-time operational and database health monitoring - Responsive high-fidelity enterprise UI ## Quick start 1. Install dependencies npm install 2. Copy the environment template cp .env.example .env.local 3. Set your Supabase, Google, and Gemini values 4. Start the app npm run dev ## Security model Site access is guarded by a secure admin passcode and a 7-digit MFA verification challenge before the dashboard is reachable. Runtime secrets remain isolated from the browser interface.
